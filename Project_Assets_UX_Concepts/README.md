# Project assets (concept work, not affiliated with Google/YouTube)
- youtube-ux-concepts-prototype.html : open in a browser; 3 interactive concept prototypes (fictional data)
- prototype-source/ : Vite + React + TypeScript source (npm install && npm run dev)
- design-system/tokens.json : Figma-compatible tokens (light, dark, dataviz); contrast-report.json = computed ratios; axe-results.json = automated a11y scan
- screens/ : wireframes, hi-fi screens, flows, IA, journey maps (SVG + PNG)
No user research or usability testing has been conducted; personas and journeys are proposed.
